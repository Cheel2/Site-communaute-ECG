# Wireframes

## Accueil — Desktop

- HEADER : Logo à gauche, menu horizontal à droite (6 liens)
- HERO : Image pleine largeur + message centré + bouton CTA "Découvrir"
- SECTION MISE EN AVANT : 3 cartes horizontales (image + titre + extrait)
- SECTION LIVRES : Grille 4 colonnes (couverture + titre + prix)
- SECTION ÉVÉNEMENTS : Liste 3 événements (date + titre + type)
- FOOTER : Liens légaux + copyright + réseaux sociaux

## Accueil — Mobile (375px)

- HEADER : Logo centré, menu hamburger à droite
- HERO : Image pleine largeur empilée + titre + bouton CTA
- SECTION MISE EN AVANT : 1 carte par ligne empilée verticalement
- SECTION LIVRES : 2 colonnes grille (couverture + titre)
- SECTION ÉVÉNEMENTS : Liste empilée (date en haut, titre en dessous)
- FOOTER : Liens empilés verticalement

## Liste livres — Desktop

- HEADER : Identique à l'accueil
- TITRE : "Nos livres" centré avec sous-titre
- GRILLE : 4 colonnes de cartes livre (couverture + titre + prix + bouton)
- FILTRE : Aucun (volume faible)
- FOOTER : Identique à l'accueil

## Liste livres — Mobile

- HEADER : Logo + hamburger
- TITRE : "Nos livres" pleine largeur
- GRILLE : 2 colonnes de cartes empilées
- FOOTER : Liens empilés

## Formulaire partenariat — Desktop

- HEADER : Identique à l'accueil
- TITRE : "Devenir partenaire" centré
- SOUS-TITRE : Texte explicatif du partenariat financier
- FORMULAIRE : 3 champs alignés (nom, email, pays) + bouton soumission
- CONFIRMATION : Message de remerciement + redirection WhatsApp
- FOOTER : Identique à l'accueil

## Formulaire partenariat — Mobile

- HEADER : Logo + hamburger
- TITRE : "Devenir partenaire" pleine largeur
- SOUS-TITRE : Texte explicatif
- FORMULAIRE : 3 champs empilés verticalement + bouton pleine largeur
- CONFIRMATION : Message + bouton WhatsApp pleine largeur
- FOOTER : Liens empilés
